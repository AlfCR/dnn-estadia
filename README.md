## Proyecto 4: Desarrollo y Validación de Redes Neuronales Profundas (DNN) para
## Mantenimiento Predictivo

Pipeline de preprocesamiento de datos de telemetría vehicular (OBD-II)
para el entrenamiento de redes neuronales profundas orientadas a
mantenimiento predictivo.
